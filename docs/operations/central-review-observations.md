# 중앙 리뷰 관측

`/review-observations`에서 저장소와 최근 7·30·90일을 선택한다. API는 `GET /api/v1/repositories/:repoId/review-observations?days=30`이다. 기존 저장소 조회 권한을 적용하고 응답을 캐시하지 않는다. 집계 전후에 인가를 확인한다. 개인 분석·다른 저장소·개인 발행 scope·사용자와 계정 식별자는 응답에 포함하지 않는다.

PR별 상태는 기간 안에 생성한 공용 분석 중 각 PR의 최신 한 건이다. 최근 2,000개 분석까지 읽으며 한도를 넘으면 표본임을 표시한다. 마지막으로 관측한 PR head와 다른 분석을 구분한다. 완료·부분 완료·실패는 분석 상태이며 결함 해결 판정이 아니다. 최신 분석에 보고서가 없으면 과거 보고서를 대신 집계하지 않는다.

새 보고서를 저장하는 transaction에 `reports.observation`을 함께 기록한다. 모델/데모/실패/미실행 출처, duration, 우선순위별 지적 수, 기준 판단과 이전 관측 비교 수를 담으며 원문·finding ID를 복제하지 않는다. 기존 보고서는 null로 유지하고 미기록 분모로 표시한다. 잘못된 형식도 미기록이다. 데모 보고서는 상태에 표시하되 지적·기준 판단·분석 시간 합계에서 제외한다. 같은 PR의 재시도 지적을 중복 합산하지 않는다.

위반 가능성·충족·미완료는 지적에 연결된 기준 판단 수이고, 미보고·연결 불가는 지적 수다. 두 단위와 미판정 분모를 섞지 않는다. 현재 기준 revision의 후보·활성·퇴역 및 판단 종류는 별도로 집계한다. 이 기록을 현재 지적의 오탐 판정이나 모델 정확도로 해석하지 않는다. 오탐률·사고 감소율은 null이며 개인별 평가를 생성하지 않는다.

호출·시간은 기간 내 공용 분석과 재시도를 모두 포함하므로 최신 PR 집계와 분모가 다르다. Model admission ledger의 예약·전송·완료·실패·중단 상태, 기록이 있는 분석 수와 입력 byte 수를 제공한다. Ledger가 없는 분석은 미관측이며 무호출을 의미하지 않는다. 보고서 duration 합계는 실제 청구 시간이나 사용자 경과 시간이 아니다. 토큰 사용량·청구 금액은 현재 미관측으로 표시한다. Provider별 실제 usage 정규화와 청구 근거 검증은 남아 있다.

공용 policy/collective의 저장된 발행 상태·sequence·기간 내 발행 수를 표시한다. Manifest와 bundle GET은 저장소 인가 이후 서버가 보낸 HTTP status·응답 시간만 UTC 일자별 합산한다. 개인 component를 포함한 GET 응답도 사용자·bundle·client ID 없이 요청 종류별 합계에만 포함한다. 요청 body·로컬 결과·실행 시간·피드백을 받지 않는다. 200과 304는 중앙 응답이며 다운로드 완료·로컬 적용·리뷰 실행의 증거가 아니다. 로컬 실행·적용은 항상 unknown이다.

응답 계측은 best effort다. 서버 프로세스당 최대 16개 쓰기, SQL 2초 제한을 두고 DB 오류·과부하 시 경고만 남긴다. 응답을 바꾸지 않으며 재전송해 중복 기록하지 않는다. 인가 이전 거부·프로세스 중단 등 누락 가능성이 있어 전체 요청 수나 성공률로 확대하지 않는다. 계측 시작 시각을 표시하고 선택 기간이 걸치는 UTC 날짜 전체를 집계한다. 기존 retention 실행에서 90일 이전 일자 버킷을 삭제하며 저장소 삭제 시 cascade한다.

Migration 51은 nullable report column과 집계 table/index만 추가한다. 기존 50개 checksum·보고서·설정을 보존한다. 구버전 워커의 저장은 null로 남아 호환된다. 이전 이미지로 되돌려도 column/table을 제거하거나 과거 지표를 생성하지 않는다. 로컬 CD·CLI·계정·모델과 중앙→로컬 전파 계약은 변경하지 않는다.

검증은 native PostgreSQL의 50→51 업그레이드, 실제 worker 저장, 개인/저장소 격리·legacy/잘못된 기록·데모 제외·최신 PR과 재시도 분리·2,000개 상한, 실제 manifest 200/304·bundle 200·인가 후 503·비로그인 미계측, 저장 실패·동시 쓰기 제한을 포함한다. 전체 페이지를 실제 API에 연결해 저장소·기간 변경·새로고침과 1360/420px 가로폭·하단 스크롤을 확인한다. 실제 모델의 품질·청구 금액과 로컬 실행 지표 수집을 검증한 것으로 확대하지 않는다.
