## 남은 제한과 종료 범위

실제 원천 검증 범위는 지정한 두 PR이다. 최초 수집 전에 이미 사라진 댓글이나 당시 저장하지 않은 수정 내용은 복원할 수 없다. `not-returned`는 최근 응답에서 빠졌다는 뜻이며 삭제 원인을 확정하지 않는다. 지침 원문의 thread가 outdated이거나 작성자가 수정했다고 답한 사실만으로 현재 코드가 수정됐다고 판단하지 않는다.
