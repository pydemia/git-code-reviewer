2026-09-15 17:01 KST 조회에서 활성 저장소 2곳의 PR 1,189건과 대화 244건을 확인했다. 원문·본문 버전·REST/스레드 관측 이력은 기존 `github_pr_messages`, `github_pr_message_versions`, `github_pr_message_observations`에 저장돼 있다. 기존 화면은 분석 결과에 종속되고 reader credential에 이력 읽기 경로가 열려 있지 않다. 기본 polling은 열린 PR과 최근 닫힌 PR만 따라가므로 지정한 과거 PR의 제한된 재수집 경로가 필요하다.

- C01: 기존 job 실행권·재시도와 메시지 저장을 재사용한다. 수집 요청은 이미 등록된 저장소의 명시한 PR 번호 최대 20개로 제한한다. PR 단위 완료·재시도 위치를 저장하며 REST의 기존 페이지 상한을 유지한다. 전체 조회가 성공한 경우에만 수집 범위와 최근 조회에서 반환되지 않은 코멘트를 기록한다. 반환되지 않음은 삭제의 확정 증거로 표현하지 않는다. 원문·과거 관측은 보존한다.
- C02: 저장소별 이력 목록·PR 원문·답글·관측 이력·수집 범위를 페이지 조회로 제공한다. 기존 `knowledge:read` credential와 저장소 reader 인가를 재사용한다. 읽기 요청에는 서버 소유 ID·cursor·revision만 허용하며 원문을 검색 요청으로 업로드하지 않는다. 분석이 없어도 중앙 화면에서 읽을 수 있게 한다.
- C03: 공용 지침을 개인 후보 승격 없이 원문에서 직접 작성한다. 기존 collective memory와 publication projection을 사용하고 저장소 관리자의 한 번의 명시적 활성화로 발행을 요청한다. source hash/관측이 바뀌거나 원문이 최근 조회에 없으면 재검토가 필요하다. 기존 개인 자료는 공용으로 바꾸지 않는다. Skill bundle 계약을 유지한다.
