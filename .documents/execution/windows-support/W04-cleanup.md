# W04 수동 정리 대상

W03에서 실행 도구의 자동 승인 검토가 재귀 삭제를 `blocked by policy`로
거절한 경로다. 상세 사유는 제공되지 않았다. W04에서는 존재 여부만 확인했고
삭제 재시도나 다른 명령·도구를 통한 우회를 하지 않았다.

현재 남아 있는 아래 폴더만 Windows 탐색기에서 수동 삭제한다. 사용자 데이터
디렉터리나 상위 Temp 폴더를 일괄 삭제하지 않는다. 이미 삭제한 항목은 다시
만들지 않는다. 정리 후 존재 여부를 읽기 전용으로 재확인할 수 있다.

18개는 실패한 초기 시험 fixture다. 마지막 Host fixture의 임시 credential·
private profile·service는 W03에서 정리됐으며 폴더만 남아 있다.
