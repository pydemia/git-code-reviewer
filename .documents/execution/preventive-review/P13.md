## 2026-09-15 — 게시 직전 GitHub head 검증

P13-C03의 게시 직전 검증을 구현했다. 관리 댓글을 쓰기 직전에 GitHub의 PR 번호·저장소·열린 상태와 분석 head SHA를 확인한다. PATCH 404 이후 marker 복구에서도 재조회하며 조회 실패·304·다른 PR·잘못된 응답은 게시를 허용하지 않는다. 조회에는 15초 제한과 no-cache를 적용한다. 이후 DB의 최신 게시 대상과 저장소·instance·credential 선택을 다시 확인해 오래된 job이 새 target을 덮거나 비활성화하지 못하게 했다.
