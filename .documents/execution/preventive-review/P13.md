# P13 — 중앙 PR 리뷰와 운영 지표

## 2026-09-15 — 공용 발행본과 기준 선택 고정

P13-C01의 중앙 PR 분석 입력 고정·선택·결과 provenance를 구현했다. Queue transaction에서 실제 공개된 policy/collective bytes와 source identity를 확인하고 analysis key에 고정값을 포함한다. 개인 bundle은 조회하지 않으며 공용 분석에서는 raw collective Memory 대신 승인된 발행 projection을 사용한다. 발행된 Skill도 queue 당시 버전을 유지한다. 새 발행본과 기존 분석을 섞거나 과거 분석에 소급 연결하지 않는다.

같은 Git SHA의 전체 변경 파일을 페이지 단위로 읽고 내용 hash와 최종 Git blob hash를 대조한다. 잘림·누락·변조·scope/byte/page/time 제한 초과는 기준 적용 성공으로 표시하지 않는다. 로컬과 공통 함수로 경로·언어·branch·symbol/contract·예외·예산을 판단하고 선택 context를 불변 이력으로 보관한다. 결과의 versions에도 발행본과 context hash를 기록한다. 원문 확보 실패는 모델 호출 없이 partial이며 예외 경계를 지난 실행도 미완료로 남긴다.

최종 14개 suite 192건, contracts/client/analysis-engine/runtime/web build와 변경 파일 ESLint를 검증했다. 실제 PostgreSQL·Git 원문과 합성 모델로 queue→기준 퇴역/재발행→고정 입력의 worker 실행→결과/API 이력, 같은 입력 재시도, 개인 context와 raw source 부재, 원문 실패의 모델 무호출을 확인했다. Browser는 실제 API로 연결한 새 component에서 기준/버전/경로 표시와 1360/420px overflow를 확인했다. 처음 추가한 API fixture의 enabled 누락을 보완했다. 이후 실패 경로에서 partial 분석의 기준 상태가 ready로 기록되는 불일치를 발견해 unavailable로 수정하고 전체 검사를 다시 통과했다.

49→50 업그레이드는 기존 queue 분석·snapshot·원문/버전·대화/재검토 queue와 49개 checksum을 보존한다. 새 필드는 null이며 선택 이력을 만들지 않고 재실행에 변화가 없다. Client alpha38 패키지는 깨끗한 Node 22.23.2와 18.20.8 consumer에서 검증했다. 기존 CD 2.9.4/client alpha37/CLI alpha33과 bundle 계약을 유지하며 강제 업데이트·창 reload·로컬 모델/계정 변경은 없다.

실제 외부 GitHub나 유료 모델 호출, PR 게시를 검증에 사용하지 않았다. 중앙 PR에서 개별 finding과 기준 판정을 연결하는 일, 실제 client/central 리뷰 표본 대조, CI 근거·재발/게시·운영 지표는 남아 있다. 전체 목표는 계속 진행 중이다. [운영 계약](../../../docs/operations/central-shared-criteria.md)에 제약과 사용 경로를 기록했다. 배포 증거는 아래에 이어서 기록한다.

## 2026-09-15 — 이전 관측 비교와 관리 댓글 갱신

P13-C03의 공용 보고서 비교와 게시 순서 보호를 구현했다. 같은 PR의 직전 공용 보고서만 비교하며 개인 분석은 제외한다. 확인한 코드 구간·정확한 설명·분석 기준이 같을 때 줄 이동과 SHA 변경을 연결한다. 중복 위치는 연결을 보류하고 현재 지적 및 재확인하지 못한 이전 지적을 유지한다. 수정 완료나 의미적 결함 재발로 판정하지 않는다. JSON/API/웹/Markdown에 저장된 비교 이력을 표시한다.

같은 분석 재시도는 게시 상태를 보존하며 새 분석은 기존 관리 댓글을 갱신한다. PostgreSQL microsecond 순서로 최신 분석을 구분한다. 개인 분석과 마지막 관측 PR head가 다른 분석은 게시하지 않고 오래된 job이 최신 target을 비활성화하지 못하게 한다. 게시 직전 GitHub head 재조회와 실제 외부 게시 검증은 남아 있다. [운영 계약](../../../docs/operations/central-review-recurrence.md)에 연결 조건과 한계를 기록했다.

26개 suite 256건이 통과했다. 별도로 실행한 DB TLS suite는 로컬 Docker의 기존 이미지 저장소 I/O 오류로 setup에 실패해 8건을 실행하지 못했다. 로그와 native PostgreSQL 정리 증거를 보존했다. Browser의 초기 5초 제한은 30초로 조정했으며 1360/420px 표시·HTML 비실행·가로 overflow를 검증했다. 추가 migration과 로컬 모델/계정/설치 변경은 없다. 전체 P13와 목표는 계속 진행 중이며 배포 증거를 이어 기록한다.
