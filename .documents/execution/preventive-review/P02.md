# P02 실행 기록

상태: 진행 중. 2026-09-13에 P02-C01의 공통 계약을 구현했다. 실제 local store·source/executor·CLI·CD backend와 P02 전체 완료 조건은 후속 commit에 남아 있다. P01의 실제 화면 검증도 별도로 남아 있다.

## C01 계약과 소비

`@gcr/client-contract`에 Node·VS Code·서버 의존성이 없는 JSON decoder와 TypeScript 타입을 추가했다. Standalone/centralized mode, profile·repository·worktree identity, 고정 source/context, memory·review-only Skill, run/file 상태와 evidence·severity·policy를 다룬다. 근거의 source/context 참조, 선택 source의 anchor, 관련 source manifest, scope·audience, 완료 coverage와 chronology를 검증한다.

Legacy confidence와 verified/limited는 보존하고 evidence는 unassessed로 가져온다. Source/test 확인에는 해당 evidence·조건·반증 검토를 요구한다. Accepted exception은 violation과 exception ID를 유지한다. Rule revision의 정책은 별도 축이며 CD projection은 항상 advisory다. CD가 표현할 수 없는 평가도 원본 report와 함께 `gcr.report`에 보존한다. CLI의 완료/후속 조치/미완료 종료 코드 0/1/2와 hook의 advisory 0은 독립적이다.

Decoder는 JSON 형식·참조를 검증한다. Hash 재계산, provenance 인증, 실제 모델·runner 실행, 현재 인가·offline lease, filesystem/network 제한은 store·resolver·executor에서 수행해야 한다. 합성 fixture를 parsing한 결과를 실제 결함 재현으로 기록하지 않는다.

세 client package를 `0.1.0-alpha.2`로 함께 올렸다. CD는 이 version의 contract만 devDependency로 설치하고 같은 fixture를 normalizer·outcome·source overlay·advisory adapter에 전달해 검사한다. Core/executors는 아직 identity만 제공하며 runtime backend 연결은 P02-C07에 남긴다. 전달 순서 조정은 [결정 기록](decisions.md)과 [package 전달 계약](../../../docs/development/client-package-delivery.md)에 명시했다.

## 검증

- GCR `pnpm exec vitest run packages/client-contract/src/index.test.ts packages/review-contract/src/index.test.ts`: 신규 63개와 기존 2개 통과. 기존 server normalizer의 verified/limited·confidence를 실제로 가져와 비교한다.
- GCR contract typecheck, test 파일 별도 TypeScript 검사, ESLint 통과. Runtime dependency·Node/VS Code 타입은 추가하지 않았다.
- `GCR_CLIENT_MIN_NODE=.../node18 pnpm pack:clients --verify`: clean build, 세 tarball 내용·version/hash, offline 설치와 Node 25.9.0 및 18.20.8 import 통과.
- CD `npm run test:client-contract`, `npm run typecheck:test`: 설치 artifact를 사용한 17개 소비 검사와 실제 `AnalysisReport` 타입 호환성 통과. Mutable source 변경 시 overlay가 사라지며 partial/cancelled/질문/예외와 Raw JSON 근거가 유지된다.

CD는 `npm ci --offline --ignore-scripts --no-audit --no-fund` 후 전체 `npm test` 90개, typecheck/build를 통과했다. Node 18.20.8에서도 설치 package 소비 검사 17개를 통과했다.

12개 report fixture의 source 본문·SHA-256·line count·byte length·Git blob ID를 대조했다. Profile·runner·test 결과는 합성 자료이며 실제 모델·runner·GUI 검증이 아니다. Fixture와 artifact hash, 전달 source commit은 CD 소비 기록에 고정한다.

## 운영과 다음 범위

이번 commit은 공통 library와 CD 호환성 검사다. GCR 서버 runtime·배포 설정이 바뀌지 않아 PRISM-DEV image는 교체하지 않았다. CD 공개 version도 2.3.0을 유지하며 VSIX 게시를 수행하지 않았다. 서버 변경 checkpoint의 rollout과 P09의 실제 Development Host·고정 VSIX·설치·게시·Marketplace 새 설치 검증은 원래 계획대로 수행한다.
