## 2026-09-15 — PR 원문·리뷰 상태·위치 이력

P12-C01의 REST 원천 보존 경로를 구현하고 배포했다. 기존 수집에서 버리던 본문 없는 제출된 승인/기각 리뷰를 보관하고 공백을 포함한 원문을 유지한다. 현재 줄이 없을 때 원래 줄을 대신 넣지 않으며 review state·review ID·답글 대상·원래 commit/줄 범위·diff hunk를 별도 provenance로 저장한다. REST에 없는 thread resolved/outdated 상태는 unknown으로 남긴다.

Migration 0046은 body-only 버전 테이블을 보존하고 immutable 관측 이력을 추가한다. 상태만 바뀌어도 새 이력이 생기며 같은 snapshot의 반복 수집은 이력이나 knowledge outbox를 늘리지 않는다. A→B→A 복귀는 별도 이력이다. PR별 저장 직렬화, 수집 시작 시각과 provider 수정 시각 비교로 늦은 응답이 최신 자료를 덮어쓰지 못하게 했다. 같은 시작 시각의 서로 다른 응답도 보수적으로 거부한다.

중앙 PR 대화에서 현재/원래 위치, 리뷰 상태, 답글 대상과 이력을 확인한다. 이력 GET은 현재 저장소 권한과 source/PR 소속을 검사하고 50건 단위 cursor를 제공한다. 원문과 diff는 text로 표시하며 빈 본문으로 Memory 후보를 만들지 않는다. 중앙 웹 조회 기능이며 local upload나 중앙 executor를 추가하지 않았다.

기준 원천에 observation hash와 실제 discussion metadata를 고정한다. 원문 선택 후 상태·위치가 바뀌면 오래된 hash로 후보를 생성할 수 없다. 변경된 출처를 참조한 기준·memory projection은 다음 발행에서 제외하며 재검토·승인이 필요하다. 이전 bundle은 수정하지 않는다. 기존 자료의 첫 metadata 관측도 출처 변경으로 취급하므로 승인된 항목의 재검토가 필요할 수 있다.
