## 구현 현황 대조

- GCR의 기존 서버·웹, tenant/repository 인가, account registry, 개인/집단 memory·Skill, 리뷰·대화·PR 게시 기능을 유지한다. 현재 인증 모드는 `development/local/oidc/proxy`이며 SAML과 client 전용 key/PKCE/device flow는 미구현이다.
- DB migration은 31개이며 마지막 파일은 `0031_registry_deletion.sql`이다. 이 확인은 파일 현황이며 운영 DB 적용 검증은 배포 단계에서 별도로 수행한다.
- `packages/client-contract`, `client-core`, `client-executors`, `apps/cli`, `apps/mcp`는 착수 시 존재하지 않는다. Local store·불변 source snapshot·signed bundle sync·공통 자동 리뷰 scheduler는 새로 구현한다.
- CD 기준에는 API provider와 Codex/Claude Code/Gemini CLI/Antigravity account adapter가 있다. Extension과 hook은 Node 18 target으로 bundle한다. `npm test`는 provider test만 실행한다. 실제 모델, 읽기 범위, 취소와 Extension Host는 이번 phase에서 별도로 검증한다.
- CD 선행 결함은 P01의 수집 정책, staged source, 실패 상태, 출력 경로·Markdown trust, backend 경계 순서로 처리한다. 새 기능을 legacy hook 차단 정책과 섞지 않는다.
