# CD의 자동 자료 출처 연결 — 2026-09-26

CD 연결 단계에서 중앙 저장소를 반드시 선택하던 동작을 없앴다. HTTPS 서버 주소와 API key를 입력하면 그 key로 현재 접근 가능한 모든 자료 출처를 연결한다. GCR의 저장소 선택은 key 권한 범위이며 CD의 연결 조건과 구분한다. 발급 시점에 포함되지 않은 저장소에는 새 key가 필요하다.

## 사용 절차

- **Central Review Connection → Connect with API key…**에서 URL과 API key를 입력한다. 사설 CA가 필요하면 GCR의 공개 CA 파일을 지정하고 서버 연결을 확인한다. 새 연결에는 JSON이나 저장소 선택이 필요하지 않다.
- **View downloaded review knowledge**에서 출처 이름별 Skill·프롬프트·지침의 내용을 확인한다. **Reference sources…**는 참고 범위를 줄이는 선택 항목이다. 현재 저장소의 정책 출처는 유지하며 다른 출처 선택을 해제해도 key나 캐시는 삭제하지 않는다.
- **Browse PR review history**의 출처 선택은 읽을 PR 이력을 좁히는 동작이다. 연결이나 전체 리뷰 범위를 바꾸지 않는다.
- 기존 단일 출처 연결과 JSON import는 보존했다. 기존 key와 같은 key의 연결은 재사용한다. 다른 key로 교체할 때에는 기존 연결을 먼저 해제한다. Standalone으로 전환했다가 저장한 출처 그룹을 복원할 수 있다.

로컬 Git remote는 로컬에서만 비교한다. 유일하게 일치한 출처의 정책을 현재 저장소 정책으로 적용한다. 다른 저장소의 자료는 적용 조건·반증을 검토할 참고 자료다. 일치하는 중앙 저장소가 없어도 연결할 수 있으며 이 경우 모든 출처를 참고 자료로 취급한다. 사용자 provider·모델·reasoning과 자동 실행 설정은 그대로다.

## 읽기와 실행 경계

기존 discovery·reader API, 서명된 bundle·암호화 캐시를 재사용했다. 출처별 audience와 snapshot·manifest hash·authorization revision을 고정하며 가장 이른 만료를 적용한다. 모든 출처는 같은 서버·tenant·사용자와 현재 profile/worktree에 속해야 한다. 추가 출처의 권한 철회도 리뷰를 중단한다. 온라인 manifest의 5분 제한을 완화하지 않았다.

관련 자료는 기존 적용 조건과 전체 문맥 한도 안에서 로컬로 선택한다. 다른 저장소의 필수 criterion을 가져와 강제하지 않는다. 출처별 버전은 결과에 남기며 모델에 전달한 자료의 근거와 실제 판단에 활용했다는 근거를 구분한다. 내려받은 코드를 실행하는 기능은 추가하지 않았다. GCR 통신은 읽기 요청이며 로컬 코드·diff·질문·결과·대화·개인 메모리 업로드나 중앙 모델 대행 실행을 추가하지 않았다.
